# 💾 SandboxNET custom internet

![PlatformIO](https://shields.io)
![Hardware](https://shields.io)
![Filesystem](https://shields.io)

**SandboxNET** — это уникальная автономная программная среда и беспроводная экосистема для микроконтроллеров ESP32. Проект превращает плату в изолированный веб-сервер с аутентичной графической оболочкой в стиле **Windows 1.0 (MS-DOS Executive)**, позволяя «на лету» загружать, каталогизировать и запускать кастомные HTML5/JS приложения без необходимости перепрошивки устройства через кабель.


---

## 🚀 Основные возможности

* **💾 Ретро-Интерфейс (Windows 1.0)**: Сине-белая палитра, шрифты фиксированной ширины, управление стрелочками на клавиатуре (`Enter` для открытия, `ArrowLeft` для возврата).
* **📱 Мобильный Пульт (ТВ-Логика)**: Специальный экранный джойстик на смартфонах для комфортного администрирования по Wi-Fi.
* **📂 Виртуальная ФС (LittleFS)**: Динамическое создание папок, иерархический просмотр структуры файлов и автоматический роутинг.
* **🌐 Динамический Лоадер**: Загрузка `.html` файлов напрямую через браузер. ESP32 считывает заголовок `<address = "...">` и создает скрытый URL-адрес для новой страницы «на лету» без перепрошивки через кабель.
* **💓 Heartbeat Session**: Механизм удержания сессий. Если пользователь закрывает вкладку приложения, ESP32 автоматически останавливает фоновые фоновые задачи (например, сценарии мигания диодов через тег `<esp>`).

## 🎮 Встроенная экосистема приложений

1. **🤪 Crazy Chef 2D (Absurd Edition)**: Симулятор готовки с пультом управления. Кнопки запоминают выбор, клик материализует предмет на ТВ, повторный клик бросает его. 12 безумных ингредиентов (носки, уран-235, котики) и генератор абсурдных заказов с физикой соскальзывания.
2. **👾 Cyber Arena 2D**: Олдскульный аренный шутер с волнами набегающих кибер-дронов, счетчиком рекордов и тач-управлением.
3. **🐍 Neon Snake**: Легендарная змейка на JS/Canvas, адаптированная под мобильные экраны и сохраняющая рекорды.
4. **📝 MS-DOS Notepad**: Текстовый редактор в DOS-стиле, позволяющий писать заметки и скачивать файлы на устройство в формате `.TXT`.
5. **🧟 Horror Cafe: IRKA**: Текстовый хоррор-квест с искусственным интеллектом шагов монстра, где нужно восстановить питание, найти ключи и сбежать из кафе.

## 🛠️ Спецификация таблицы разделов

Поскольку библиотеки `WiFi`, `WebServer` и `LittleFS` занимают много памяти, стандартная разметка ESP32 выдаст ошибку переполнения. В проекте используется оптимизированная конфигурация **No OTA**, расширяющая память под код до 2 МБ и под файлы до 1.9 МБ.

Создай файл `custom_partitions.csv` в корне проекта:
```csv
# Name,   Type, SubType, Offset,  Size, Flags
nvs,      data, nvs,     0x9000,  0x5000,
otadata,  data, ota,     0xe000,  0x2000,
app0,     app,  factory, 0x10000, 0x200000,
spiffs,   data, spiffs,  0x210000,0x1F0000,
```

## ⚙️ Настройка `platformio.ini`

Приведи конфигурационный файл проекта к следующему виду:

```ini
[env:nodemcu-32s]
platform = espressif32
board = nodemcu-32s
framework = arduino
monitor_speed = 115200
board_build.filesystem = littlefs
board_build.partitions = custom_partitions.csv
upload_flags =
    --before=default_reset
    --after=hard_reset
```

## 📦 Инструкция по установке

1. Клонируй репозиторий и открой его в **VS Code** с установленным расширением **PlatformIO**.
2. Помести код `main.cpp` в директорию `src/`.
3. Создай в корне проекта папку `data/` и положи туда стартовый интерфейс `index.html`.
4. Подключи ESP32 через USB-кабель.
5. Выполни очистку памяти (Task: **Erase Flash**), чтобы применить новые разделы.
6. Нажми кнопку **Upload** (Стрелочка внизу) для прошивки C++ кода.
7. Открой меню PlatformIO (иконка муравья) -> Platform -> нажмите **Build Filesystem Image**, а затем **Upload Filesystem Image** для загрузки интерфейса во Flash.

## 📶 Как подключиться и играть

1. Включи Wi-Fi на смартфоне или ПК.
2. Найдите сеть **`MS-DOS_ESP32`** и подключитесь к ней (пароль: **`SuperPassword123`**).
3. Открой любой браузер и введи адрес: **`http://192.168.4.1`**
4. Пользуйся меню **LOAD** для отправки на плату файлов `crazy_chef.html`, `shooter.html` или `horror.html` и управляй своей карманной ретро-станцией!
